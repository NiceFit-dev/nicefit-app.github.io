# NiceFit App prototipo N°1

Pasos para iniciar el proyecto:

1. Para iniciar el proyecto por primera vez, primero debes clonarlo de este repositorio.
`git clone git@github.com:NiceFit-dev/nicefit-app.git`

2. Luego debes entrar al proyecto
`cd nicefit-app`

3. Ejecutar los contenedores
`docker compose up --build`
